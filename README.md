# Synapse Extras

> **Modular Opt-In Add-ons & Extended Workflows for SynapseOS**

Synapse Extras provides extended wallpapers, cyberdeck sound effects, and specialized agent workflows for SynapseOS power users without bloating the core live ISO image.

See [SCOPE.md](SCOPE.md) for architectural guidelines and package breakdowns.

---

## 📦 Subdirectories
- `themes/`: Curated high-res cyberdeck wallpapers and alternative themes.
- `audio/`: System chimes, PipeWire DSP profiles, and tactile audio alerts.
- `workflows/`: Specialized agent workflow automation packs.
- `packages/`: Arch Linux PKGBUILD recipes for installer netinstall integration.
